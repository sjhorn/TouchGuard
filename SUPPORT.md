# Getting help

- **FAQ:** <https://blog.hornmicro.com/TouchGuard/support/> covers permissions, choosing a delay, starting at login and uninstalling.
- **Bugs and ideas:** [open an issue](https://github.com/sjhorn/TouchGuard/issues/new/choose).
- **Security:** see [SECURITY.md](SECURITY.md). Please don't use public issues for security problems.

TouchGuard is maintained in spare time, so replies may take a few days.
